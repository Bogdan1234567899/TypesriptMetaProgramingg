# Task 3 — Test Quality

## Гілки методу Check

1. `string.IsNullOrEmpty(pwd)` → `"Empty"`
2. `pwd.Length < 8` → `"Too short"`
3. містить цифру → `"Has digits"`
4. валідний → `"OK"`

## Метрики

| Метрика | Before | After | Поріг | Статус |
|---|---|---|---|---|
| Branch coverage | 25% (1/4) | 100% (4/4) | >= 90% | PASS |
| Mutation killed | 0 | 1 | >= 1 | PASS |

## Mutation-перевірка

Розглянув мутацію: замінити `<` на `<=` у `pwd.Length < 8`.
- Без покриття гілки "OK" з рядком довжиною рівно 8 — мутація не виявляється.
- Мій тест `"password"` (8 символів) очікує `"OK"`. З мутацією поверне `"Too short"` → тест падає → мутант killed.

## Quality Gate

Поріг: Branch coverage >= 90% і Mutation killed >= 1
Статус: **PASS**

## Висновок

Додав 3 тести (Empty, Too short, Has digits) — тепер усі 4 гілки покриті. Mutation-аналіз показав, що тести не просто проходять, а реально перевіряють межі (граничний випадок довжини 8). Дефект у логіці буде помічений тестами, а не у продакшені.
